MUCars — Prédiction des prix de voitures au Maroc

Une application de prédiction des prix de voitures d’occasion au Maroc, basée sur les caractéristiques du véhicule et un modèle K-Nearest Neighbors (KNN).

De la description du véhicule au prix estimé

Interface et prédiction

Captures réelles de l’application Gradio exécutée localement.

01

Renseigner les caractéristiques

Marque, année, kilométrage, puissance fiscale, carburant, boîte de vitesses, état et origine du véhicule.

Formulaire interactif de prédiction développé avec Gradio.

02

Consulter le prix estimé

Exemple : 114 200 MAD pour les caractéristiques saisies, avec une fourchette indicative affichée de 102 780 à 125 620 MAD.

Exemple de prédiction ; la fourchette présentée par l’application n’est pas une garantie de prix.

Objectif

Estimer le prix d’un véhicule d’occasion au Maroc à partir d’informations saisies par l’utilisateur, grâce à une application simple et interactive.

Approche Machine Learning

01 · DonnéesDataset MUCars-2024 : 101 896 annonces au total ; modèle présenté comme entraîné sur 74 900 annonces.
02 · PrétraitementEncodage des catégories, imputation et mise à l’échelle des variables.
03 · ModélisationRégression K-Nearest Neighbors (K=5) avec scikit-learn.
04 · InterfaceFormulaire et affichage des résultats via Gradio.

Performances affichées

  • R² : 0,76
  • MAE : 27 489 MAD
  • RMSE : 52 809 MAD

Détection et reconnaissance de plaques marocaines

Application capable de détecter automatiquement les plaques d'immatriculation marocaines, d'identifier leurs caractères, de reconstruire le numéro et d'associer le code numérique à la préfecture ou province correspondante.

Application en action

Du chargement de l'image au résultat

Les étapes de l'application Streamlit à travers des captures réelles.

01

Interface d'entrée

Sélection du mode image et chargement du fichier à analyser.

Interface d'accueil et paramètres de détection.

02

Analyse en cours

Le fichier est chargé et l'application lance le traitement.

État de traitement affiché pendant l'analyse.

03

Résultat : plaque et région reconnues

L'application affiche le nombre de plaques détectées, le texte extrait et la région associée au code administratif.

Exemple réel : une plaque détectée et une région identifiée.

04

Mode vidéo

L'interface propose également l'import de vidéos MP4, AVI ou MOV.

Sélection du mode vidéo dans l'application.

Le problème

L'objectif est d'automatiser l'analyse d'images ou de vidéos contenant des véhicules afin d'extraire les informations visibles sur leurs plaques d'immatriculation. Le projet combine localisation de la plaque, détection des caractères et interprétation du code administratif marocain.

Pipeline de traitement

01 · Image / vidéoEntrée fournie à l'application Streamlit.
02 · DétectionPremier modèle YOLO pour localiser la plaque.
03 · ExtractionRecadrage de la zone correspondant à la plaque.
04 · CaractèresSecond modèle YOLO pour détecter les caractères.
05 · ReconstructionClassement spatial des caractères pour reconstruire le numéro.
06 · PréfectureAssociation du code numérique à la région d'origine.

Architecture du système

Deux modèles YOLO

  • License Plate Detector — localisation des plaques dans l'image.
  • Character Detector — détection des caractères présents sur la plaque.

Entraînement

Les modèles ont été entraînés avec Google Colab et un environnement GPU. Deux jeux de données distincts ont été utilisés : un pour les plaques et un pour les caractères. Les modèles entraînés sont ensuite intégrés à l'application.

Application

  • Interface Streamlit.
  • Traitement d'images.
  • Traitement de vidéos et des frames.
  • Annotation des résultats avec OpenCV.

Technologies

Python YOLO Ultralytics OpenCV Streamlit NumPy Google Colab

Football AI Predictor

Un système de prédiction des résultats de matchs internationaux — victoire à domicile, match nul ou victoire à l'extérieur — combinant feature engineering, Gradient Boosting, API serverless AWS et dashboard Plotly Dash.

47 399Matchs internationaux dans le jeu de données historique (1872–2024)
56,28 %Accuracy rapportée pour le modèle final Gradient Boosting
3 issuesVictoire domicile, nul ou victoire extérieur
Démonstration

De la sélection des équipes à la prédiction

Captures réelles de l'application déployée.

01

Configurer le match

Choix des équipes, du lieu (domicile, extérieur ou neutre) et du type de rencontre (officielle ou amicale).

Dashboard Plotly Dash connecté à une API de prédiction.

02

Visualiser les résultats

Prédiction et probabilités des trois issues, diagramme en anneau, radar de comparaison et histogramme.

Les probabilités représentent les sorties du modèle, et non des résultats garantis.

03

Consulter l'historique

Historique des résultats conservé pendant la session.

Objectif

Construire une chaîne Machine Learning de bout en bout pour estimer l'issue d'un match international en exploitant l'historique des rencontres et des indicateurs sportifs.

Pipeline de traitement

01 · DonnéesRésultats historiques internationaux, 1872–2024.
02 · PréparationNettoyage, sélection des matchs et préparation des variables.
03 · FeaturesForme récente, buts, classement FIFA, points et confrontations directes (H2H).
04 · ModélisationComparaison Random Forest / Gradient Boosting et améliorations progressives.
05 · InférenceModèle exposé via AWS Lambda et API Gateway.
06 · VisualisationDashboard Dash / Plotly hébergé sur Render.

Architecture cloud

Amazon S3 pour les artefacts, AWS Lambda pour l'inférence, API Gateway pour l'endpoint REST et EventBridge pour la mise à jour hebdomadaire annoncée dans le projet.

Évolution de l'accuracy

  • Random Forest (baseline) : 48,08 %
  • Gradient Boosting : 52,86 %
  • Filtrage post-1990 : 54,70 %
  • Classement FIFA : 56,04 %
  • Confrontations directes (H2H) : 56,28 %

Fonctionnalités

  • Prédiction de trois issues et probabilités associées.
  • Comparaison des équipes et des points FIFA.
  • Choix du terrain et du type de match.
  • Historique des prédictions pendant la session.
  • API REST de prédiction serverless.

Data Engineering · Machine Learning · MLOps

HR Analytics & Attrition Prediction

Une chaîne de données et de machine learning pour transformer des données RH en estimations de risque d'attrition, visualisées dans un simulateur interactif.

De la donnée à la décision

Architecture, orchestration et simulation

Trois captures réelles du projet : architecture fonctionnelle, exécution Prefect et application Dash.

01

Simulateur interactif d'attrition

Formulaire de profil collaborateur et estimation du risque de départ. La capture illustre un scénario affichant 31,4 % de risque, et non la performance globale du modèle.

02

Architecture Data Engineering & MLOps

Ingestion CSV vers Snowflake, transformations dbt, contrôles de qualité, suivi de dérive envisagé avec Evidently, entraînement Random Forest, registre MLflow et recommandations DiCE.

03

Orchestration Prefect

Exemple de flow terminé avec succès : ingestion, préparation, qualité des données et étape de machine learning. Capture d'une exécution antérieure.

Pipeline et modèle

Les données RH sont chargées dans Snowflake, préparées via dbt et vérifiées avant l'entraînement. Un Random Forest est optimisé avec GridSearchCV et validation croisée stratifiée. MLflow centralise les expériences et les versions du modèle.

Simulation et explicabilité

Le dashboard Dash permet d'explorer des profils employés et leurs risques estimés. Le projet intègre une approche de simulation « What-if » et de recommandations contrefactuelles avec DiCE.
